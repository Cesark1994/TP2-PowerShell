Ejercicio 1: Saludar al usuario

Este programa pide el nombre y luego muestra un saludo.

$nombre = Read-Host "Ingrese su nombre"
Write-Host "¡Hola $nombre!"

Ejercicio 2: Calcular la paga

Este programa solicita las horas trabajadas y el costo por hora, y calcula el total.

$horas = [decimal](Read-Host "Ingrese las horas trabajadas")
$costo = [decimal](Read-Host "Ingrese el costo por hora")
$paga = $horas * $costo
Write-Host "La paga que le corresponde es: $ $paga"

Los programas se pueden descargar desde el repositorio. Para ejecutarlos hay que utilizar una consola PowerShell en una computadora.
